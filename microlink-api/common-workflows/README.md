# Microlink Common Workflows

Copy-paste `GET` requests against `https://api.microlink.io`. Read fields from the JSON `data` object. `curl --data-urlencode` encodes the value after `=`.

- [metadata.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/metadata.md): normalized metadata
- [screenshot.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/screenshot.md): page screenshot
- [pdf.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/pdf.md): PDF
- [embed.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/embed.md): one field as the response body
- [scraping.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/scraping.md): custom fields with CSS rules
- [all-links.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/all-links.md): links from a page
- [all-images.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/all-images.md): images from a page
- [page-markdown.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/page-markdown.md): page as markdown
- [page-text.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/page-text.md): page as text
- [page-html.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/page-html.md): page as HTML
