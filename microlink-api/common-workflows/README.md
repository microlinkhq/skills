# Microlink Common Workflows

Copy-paste recipes using `microlink.io`. Product methods return a direct result.

- [metadata.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/metadata.md): extract normalized metadata from a URL
- [screenshot.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/screenshot.md): generate a page screenshot
- [pdf.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/pdf.md): generate a PDF
- [embed.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/embed.md): return assets directly with `embed`
- [scraping.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/scraping.md): extract custom fields with CSS rules
- [all-links.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/all-links.md): extract all links from a target URL
- [all-images.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/all-images.md): extract all images from a target URL
- [page-markdown.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/page-markdown.md): turn a whole page into markdown
- [page-text.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/page-text.md): turn a whole page into text
- [page-html.md](https://raw.githubusercontent.com/microlinkhq/skills/master/microlink-api/common-workflows/page-html.md): turn a whole page into HTML
